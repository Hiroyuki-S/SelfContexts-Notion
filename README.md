# SelfContexts-Notion

Notionで自分のコンテキストを蓄積する。

自分を知り、強みを活かし、弱みを改善するための振り返りシステム。
平日の夜、散歩しながらスマホのClaudeに音声で答えると、Notionに記録される。

## 構成

| ディレクトリ | 内容 |
|-------------|------|
| `docs/reflection-design.md` | 設計メモ（質問項目・DB構造・運用の全体像） |
| `.claude/skills/reflection/questions.yaml` | 質問セットの定義。**質問を変えたいときはここだけ直す** |
| `.claude/skills/reflection/SKILL.md` | 進行手順・聞き手としての態度・Notion書き込み仕様 |

## Notion

**🪞 SelfContexts** ページ配下に3つのDBを持つ。

- **🌙 振り返りログ** — 日次/週次/月次/四半期の問答をそのまま記録（根拠データ）
- **🧭 自己理解台帳** — 自分についての仮説を1行1件で管理（仮説→検証中→確信あり／棄却）
- **🎯 目標** — 人生目標 / 中長期目標 / 短期目標。`レビュー頻度` で、どの振り返りで扱うかが決まる

## 振り返りの種類

| 種別 | 頻度 | 所要 | 扱う目標 |
|------|------|------|---------|
| 日次 | 平日の夜（飛ばしてよい） | 約3分 | なし |
| 週次 | 日曜の夜 | 約15分 | 短期目標 |
| 月次 | 月末・月初 | 約30分 | 中長期目標 |
| 四半期 | 3ヶ月ごと | 約60分 | 人生目標 |

記録は飛ぶ前提で設計している。連続記録日数は追わないし、集計は記録がある日だけを母数にする。
